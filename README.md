# 🎓 StudyFlow — منصة الدراسة والتبادل الأكاديمي الذكية (PWA)

تطبيق ويب تقدمي (Progressive Web App) متكامل، سريع، وقابل للتثبيت على هواتف **Android** و **iOS** وأجهزة الحاسوب، مخصص لطلبة وأساتذة الجامعات لمتابعة المقاييس الأكاديمية، مراجعة المحاضرات بنظام التكرار المتباعد (Spaced Repetition)، التفاعل في المجتمع الطلابي، والاستعانة بمساعد أكاديمي ذكي مدعوم بنماذج Google Gemini.

---

## 🌟 الميزات الجوهرية (End-to-End Features)

1. **تطبيق ويب تقدمي قابل للتثبيت (Installable PWA):**
   - يدعم التثبيت المباشر من المتصفح (Android Chrome, Samsung Internet, iOS Safari).
   - يتضمن `manifest.json` كامل بمعايير standalone، وأيقونات دقيقة (192px، 512px، وأيقونة Maskable مع Safe-Zone).
   - شريط وزر تثبيت مدمج في الواجهة مع إرشادات مخصصة لمتصفح Safari على هواتف iPhone.

2. **العمل دون اتصال والتخزين المحلي (Offline First & Persistence):**
   - Service Worker (`sw.js`) يقوم بالتخزين المسبق لواجهة التطبيق واستراتيجية Network-First للبيانات الأكاديمية.
   - حفظ ملاحظات المحاضرات الشخصية، تقدم دراسة المقاييس، بطاقات الاستذكار المخصصة، وسجل محادثة الذكاء الاصطناعي في `localStorage`.
   - شريط تنبيه فوري وذكي عند انقطاع الاتصال مع زر لإعادة المحاولة.

3. **دعم كامل للغات وتعدد الاتجاهات (RTL / LTR):**
   - **العربية (RTL):** الواجهة الافتراضية باتجاه اليمين إلى اليسار.
   - **الفرنسية (Français - LTR)**
   - **الإنجليزية (English - LTR)**
   - تبديل فوري وسلس للغة من الشريط العلوي وقسم الملف الشخصي مع حفظ التفضيل.

4. **نظام البطاقات التعليمية والتكرار المتباعد (Spaced Repetition):**
   - بطاقات تفاعلية بتقنية الـ 3D Flip لمراجعة السؤال والحل.
   - تقييم ثلاثي مبني على خوارزمية Leitner (صعب، متوسط، سهل) لتحديد موعد المراجعة القادم.
   - نموذج إضافة بطاقات جديدة وحفظها محلياً وفورياً.

5. **المقررات والمحاضرات (Academic Course Hub):**
   - تصفح المقاييس الأكاديمية وتتبع نسبة الإنجاز لكل مقياس.
   - فتح المحاضرات، قراءة الملخصات وأهم نقاط الاختبار.
   - كتابة وحفظ ملاحظات دراسية خاصة لكل محاضرة.
   - تحديد المحاضرة كمكتملة ومُراجعة.

6. **المجتمع الطلابي والمناقشات (Academic Community):**
   - نشر استفسارات، ملخصات، وروابط مراجع وملفات.
   - التفاعل بالإعجاب (Likes) وحفظ المنشورات في المفضلة (Bookmarks).
   - كتابة تعليقات ومناقشات أكاديمية في الوقت الفعلي.

7. **المساعد الدراسي الذكي (Gemini AI Tutor):**
   - مدعوم عبر مسار خلفي آمن على الخادم `/api/ai/study-assistant` بدون كشف مفاتيح الـ API في جهة العميل.
   - أسئلة مقترحة سريعة لشرح المفاهيم، حل التمارين وتلخيص المواد.
   - نسخ الإجابات بضغطة زر وحفظ سجل المحادثات.

## 🚀 التشغيل المحلي (Local Development)

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. إعداد المتغيرات البيئية:
انسخ ملف `.env.example` إلى `.env`:
```bash
cp .env.example .env
```
أضف مفتاح Gemini API الخاص بك:
```env
GEMINI_API_KEY="AIzaSy..."
PORT=3000
```

### 3. تشغيل خادم التطوير:
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

## 📱 التثبيت على الهواتف (PWA Installation)

### على نظام أندرويد (Google Chrome / Samsung Internet):
1. افتح رابط التطبيق في المتصفح.
2. اضغط على زر **"تثبيت التطبيق"** الظاهر في أعلى الشاشة أو من قائمة خيارات المتصفح (⋮) -> **"إضافة إلى الشاشة الرئيسية"**.
3. سيعمل التطبيق في نافذة مستقلة كاملة الشاشة بدون شريط المتصفح مثل أي تطبيق محلي.

### على هواتف آيفون (Apple iOS Safari):
1. افتح رابط التطبيق في متصفح Safari.
2. اضغط على زر **المشاركة (Share)** أسفل الشاشة.
3. مرر للأسفل واضغط على **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**.

## ☁️ خطوات النشر على Vercel (Deployment)

1. ارفع المشروع إلى مستودع **GitHub**.
2. سجل الدخول إلى [Vercel](https://vercel.com) واختر **Add New Project** ثم استورد المستودع.
3. سيتعرف Vercel تلقائياً على إعدادات المشروع بفضل ملف `vercel.json`:
   - **Framework:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. في قسم **Environment Variables**، أضف:
   - `GEMINI_API_KEY`: مفتاح Google Gemini API الخاص بك.
5. اضغط **Deploy**.

## 🔒 حماية مفاتيح API
- تطبيق StudyFlow يتبع المعايير الأمنية الصارمة: لا يتم تضمين أي مفتاح API سري في كود المتصفح أو ملفات الحزمة المجمعة (`dist/`).
- جميع طلبات الذكاء الاصطناعي تمر عبر الخادم الخلفي (`server.ts` / `/api/ai/study-assistant`).
